Content adapters are used to build dynamic pages, most commonly for generating API documentation. A pre-build script creates a structured JSON file, and the content adapter reads that `data` file to automatically generate pages. For usage details, see the [official documentation](https://gohugo.io/content-management/content-adapters/).
